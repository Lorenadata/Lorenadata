## What I work on

- **Official statistics.** Survey-weighted analysis of INE microdata (ECV 2024): poverty, inequality and housing.
- **Data quality.** Cleaning and auditing large datasets: missing-data mechanisms (MCAR/MAR/MNAR), duplicates, univariate and multivariate outliers (IQR, LOF).
- **Data modelling.** Relational schemas designed around real domain rules, in SQL and PostgreSQL/PostGIS.
- **Building products.** Full-stack development with Python (FastAPI) and React, in production with payments and over 2,000 automated tests.
